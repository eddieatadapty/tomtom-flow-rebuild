# TomTom GO Expert Growth Audit

**Live → https://eddieatadapty.github.io/tomtom-flow-rebuild/**

Five ideas to turn more TomTom GO Expert users into subscribers, each built into a clickable version of TomTom GO Expert's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask what the drive is for, then show the setup it made | +10–20% CR to trial or purchase |
| 02 | Let the vehicle pick the paywall | +10–15% ARPU |
| 03 | Clear the road to the paywall | +10–15% CR to trial or purchase |
| 04 | Their map, downloading, before the price | +5–15% CR to trial or purchase |
| 05 | One shorter plan for people who close it | +5–10% ARPU |

Every price, rating and feature comes from TomTom GO Expert's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for TomTom GO Expert. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
